# Nageshwer Chib - Personal Portfolio

Welcome to my personal portfolio website! This repository contains the source code for my interactive, responsive, and modern portfolio.

## 🚀 Live Demo
You can view the live portfolio here: [Nageshwer's Portfolio](https://nageshwarchib1.github.io/MY-PORTFOLIO/)

## ✨ Features
- **Modern UI/UX**: Clean and professional design featuring glassmorphism and subtle gradient effects.
- **Dark/Light Mode**: Fully functional theme toggle that remembers user preferences.
- **Interactive Animations**: Smooth scroll animations (AOS), dynamic background particles, and a typing effect.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- **Dynamic Filtering**: Easily sort through certifications by category.
- **Projects Showcase**: Detailed project cards with live demo and source code links.

## 🛠️ Technologies Used
- **HTML5**: Semantic structure and layout.
- **CSS3**: Custom styling, CSS Variables, Flexbox/Grid, and media queries.
- **Vanilla JavaScript**: DOM manipulation, interactive animations, and form handling.
- **Font Awesome**: Icons for contact links, buttons, and tools.
- **Google Fonts**: Inter & Outfit typography.

## 📂 Project Structure
- `index.html`: The main structural entry point of the website.
- `style.css`: All the styling rules, custom properties, and responsive media queries.
- `script.js`: Contains logic for animations, mobile menu, theme switching, and gallery filters.
- `assets/`: Contains project screenshots, certification images, and the website favicon.

## 📥 Getting Started Locally
To run this project on your local machine:
1. Clone this repository:
   ```bash
   git clone https://github.com/nageshwarchib1/MY-PORTFOLIO.git
   ```
2. Open the directory and launch `index.html` in your favorite web browser, or use an extension like **Live Server** in VS Code.
